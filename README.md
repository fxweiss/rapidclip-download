# RapidClip

Keep the gems, lose the fat.

## Download

- **Mac** (Apple silicon, macOS 13 or later): [RapidClip.dmg](https://github.com/fxweiss/rapidclip-download/releases/latest/download/RapidClip.dmg). Open it and drag RapidClip to Applications.
- **Windows** (10 or 11, 64-bit): [RapidClip-Setup.exe](https://github.com/fxweiss/rapidclip-download/releases/latest/download/RapidClip-Setup.exe). Open it to install. If Windows says it protected your PC, click **More info › Run anyway**.
- **Linux** (64-bit): [RapidClip.AppImage](https://github.com/fxweiss/rapidclip-download/releases/latest/download/RapidClip.AppImage). Make it executable and open it. Or, on Ubuntu and Debian, [RapidClip.deb](https://github.com/fxweiss/rapidclip-download/releases/latest/download/RapidClip.deb), which doesn't update itself: install the new one over it.

RapidClip updates itself.
